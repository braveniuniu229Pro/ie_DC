# OSPF协议基础
## ospf报文类型
- hello ：发现和维护邻居关系
- Database Description（DD）：交互链路状态数据库摘要
- Link state request（LSR） ：请求特定链路状态信息
- **LSU报文** ：Link State Update（LSU）：发送详细的链路状态信息
- LSACK ：确认LSA
## 基础术语
- RouterID：用于在一个自治系统内部唯一标识一台运行OSPF的路由器，是一个32位的无符号整数。
  - Router ID选举规则：
  1. 手动配置OSPF路由器的RouterID
  2. 如果没有手动配置的话，选取lo接口中最大的
  3. 如果前两者都没有，选择物理接口中ip地址最大的
